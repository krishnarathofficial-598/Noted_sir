# Notehouse — version 02 / Midnight Club

Open `index.html` in a browser. Version 02 opens on the Midnight Club direction: a cinematic, low-light study space with warm brass accents. The pill selector now contains three visual systems:

1. Paper room — editorial, warm, tactile
2. Midnight club — dark, cinematic, reflective
3. Grid studio — crisp, modular, utilitarian

Each theme changes the page palette, display type, navigation treatment, hero atmosphere, desk illustration, cards, and footer styling. The layout is responsive and uses CSS-only illustration shapes, so there are no image assets or build steps required.
